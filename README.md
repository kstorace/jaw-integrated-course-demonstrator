## Presentation boundaries

Course demonstrator under DEC-026, using accepted synthetic Alex/Tavera material. No production authentication, authorisation, tenant isolation, server-side persistence or operational deployment controls are implied.

The interface currently supports English only. German interface support is displayed as planned/unavailable; the illustrative entry does not select or persist a language. Application document output language remains a separate explicit decision.

State is stored locally in the current browser/origin. Reset demo clears the demonstrator's imported evidence, Profile and application history in that browser. A new hosting origin does not import progress from the historical publication. JAW does not transmit applications to employers; submission recording is applicant-reported demonstration state.
